# Moonshi Studio Website Design Principles

更新日期：2026-06-21

這份文件把 UI/UX、前端工程、全端工程與網站架構的專業原則轉成 Moonshi 沐煦網站的執行準則。網站目前的主要任務不是展示技術，而是讓使用者快速理解服務、確認規則，並回到 LINE 完成預約。

## 參考來源

- W3C WCAG 2.2：無障礙內容準則，重點包含可感知、可操作、可理解、穩健。
- Nielsen Norman Group 10 Usability Heuristics：可用性準則，重點包含狀態可見、與真實世界一致、錯誤預防、一致性與辨識優先。
- web.dev Web Vitals：以 LCP、INP、CLS 等核心指標衡量網站速度、互動與穩定性。
- MDN Lazy Loading：非關鍵資源應延後載入，縮短初始載入路徑。
- The Twelve-Factor App Config：設定與內容資料應集中管理，避免散落在程式碼各處。
- OWASP Content Security Policy Cheat Sheet：網站即使是靜態頁，也要減少第三方與外部連結帶來的風險。

## 1. 使用者目標先於頁面裝飾

Moonshi 網站的核心流程是：看懂工作室定位、確認價格與須知、複製預約模板、回到官方 LINE。首頁與 LINE 圖文選單對應的每一頁都只能有一個主要任務，避免讓使用者在同一頁同時做太多判斷。

執行規則：

- 每個頁面都要有清楚的 `h1`，並對應 LINE 圖文選單的入口。
- 主要 CTA 固定指向預約須知或官方 LINE，不分散到太多外部連結。
- 圖片可以承載品牌氛圍，但重要規則與預約資訊必須保留文字版本。

## 2. 導覽一致，讓使用者不用重新學習

導覽名稱、頁面標題與圖文選單命名應一致。使用者從 Instagram、LINE 或 Google Maps 進入任一頁，都應能快速回到「價目表、工作室須知、優惠活動、工作室位置、預約」。

執行規則：

- 主導覽在所有頁面使用一致順序與一致命名。
- 目前所在頁不必過度突出，但導覽不可缺少主要入口。
- 外部連結需要清楚標示目的，例如 Instagram、LINE、Google Maps。

## 3. 無障礙是正式網站的基本品質

Moonshi 的視覺風格可以柔和，但互動狀態必須明確。鍵盤使用者、螢幕閱讀器與手機使用者都應能完成主要任務。

執行規則：

- 所有頁面提供「跳到主要內容」連結。
- 鍵盤焦點狀態要清楚可見。
- 圖片需有合理的 `alt`，尤其是價目表、預約須知與地圖圖像。
- 頁面使用語意化結構：`header`、`nav`、`main`、`section`、`footer`。

## 4. 效能優先處理圖片與版面穩定

這個網站主要素材是 Logo、價目表、預約須知與地圖。圖片是最大的載入成本，因此需要以 WebP、尺寸宣告與延遲載入控制速度和版面跳動。

執行規則：

- 網站用圖片優先使用 WebP。
- 非首屏圖片加上 `loading="lazy"` 與 `decoding="async"`。
- 圖片加上 `width`、`height`，避免載入時版面位移。
- CSS 盡量維持單一主檔，避免為小型靜態站導入過重框架。

## 5. 內容與設定集中，降低維護成本

Moonshi 後續會更新價格、地圖、優惠與預約規則。網站架構應讓這些更新集中在少數位置，避免每次都要逐頁搜尋。

執行規則：

- 外部連結、地址、品牌基本資訊集中放在 `assets/js/site-config.js`。
- 可公開部署的素材放在 `assets/images/`。
- 原始素材、IG 截圖與內部整理資料放在 `content/`，不直接部署。
- 每次素材更新後，同步更新 README 或對應文件，避免未來不知道哪個版本是正式版。

## 6. 靜態網站也要有安全邊界

目前網站是靜態頁，風險比動態系統低，但仍要避免把未來會變成問題的習慣帶進來。

執行規則：

- 不把 GitHub token、LINE 後台資料、個資或客戶預約內容放進 repo。
- 外部連結使用 `target="_blank"` 時，同步加上 `rel="noreferrer"`。
- 未來若加入表單或後端，必須先處理輸入驗證、資料保存與權限控管。
- 若日後接上自訂網域，可再評估 CSP 與安全標頭。

## 7. 品牌語氣保持溫柔但清楚

Moonshi 沐煦不是一般美容模板站。文案要保留「問題肌管理、溫和評估、先理解再施作」的品牌方向，同時避免過度抽象，讓第一次來的人知道下一步該做什麼。

執行規則：

- 避免泛用美容字眼堆疊，例如「頂級、奢華、最強、立即變美」。
- 優先說明：適合誰、預約前要準備什麼、如何判斷目前是否能施作。
- 官方 LINE 是主要轉換入口；網站負責建立信任與降低預約摩擦。
